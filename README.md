Una aplicación web moderna y responsiva para la gestión de pedidos de comida a domicilio, diseñada específicamente para optimizar la logística de delivery en la ciudad de **Cusco, Perú**.

## 🚀 Características Principales

- **Menú Dinámico:** Visualización de categorías y productos consumidos desde una API externa.
- **Gestión de Carrito:** Sistema de persistencia local (LocalStorage) para no perder el pedido al recargar la página.
- **Checkout Inteligente:** Formulario de pago y entrega con selección de distritos locales (Wanchaq, San Sebastián, etc.) y referencias exactas para el repartidor.
- **Panel de Administración:** Gestión de pedidos realizados para el control interno del negocio.
- **Diseño Adaptativo:** Interfaz optimizada para dispositivos móviles y escritorio usando Tailwind CSS.

## 🛠️ Tecnologías Utilizadas

- **Frontend:** [React.js](https://reactjs.org/) con [Vite](https://vitejs.dev/) para un desarrollo ultra rápido.
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/) para una UI moderna y modo oscuro integrado.
- **Estado Global:** React Context API para la gestión del carrito y órdenes.
- **Animaciones:** Framer Motion para transiciones fluidas en modales y menús.
- **Iconografía:** Lucide React / FontAwesome.
